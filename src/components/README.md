# Components

This directory contains all React/Vue/Angular components.

## Structure

- **common/**: Reusable UI components (Button, Input, Card, Modal, etc.)
- **features/**: Feature-specific components (CourseCard, LessonList, etc.)
- **forms/**: Form-related components (LoginForm, RegistrationForm, etc.)

## Naming Convention

- Use PascalCase for component names
- One component per file
- Component file should match component name (e.g., `Button.tsx` for `Button` component)
