# Store

State management (Redux, Zustand, Pinia, Vuex, NgRx, etc.).

## Structure

- **slices/**: Feature-based state slices
- **actions/**: Action creators
- **reducers/**: Reducers (if using Redux)
- **selectors/**: State selectors
- **index.ts**: Store configuration

## Examples

- authSlice.ts
- courseSlice.ts
- userSlice.ts
