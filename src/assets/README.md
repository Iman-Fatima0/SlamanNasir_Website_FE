# Assets

Static assets used in the application.

## Structure

- **images/**: Image files (PNG, JPG, SVG, WebP)
- **fonts/**: Font files (WOFF, WOFF2, TTF)
- **icons/**: Icon files (SVG, icon fonts)
- **videos/**: Video files (MP4, WebM)

## Best Practices

- Optimize images before adding
- Use appropriate formats (WebP for images, WOFF2 for fonts)
- Organize by feature or purpose
- Keep file sizes reasonable
