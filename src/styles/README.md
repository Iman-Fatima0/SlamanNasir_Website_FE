# Styles

Global styles, themes, and styling utilities.

## Structure

- **components/**: Component-specific styles
- **layouts/**: Layout-specific styles
- **themes/**: Theme definitions (colors, typography, spacing)
- **utilities/**: Utility classes (margins, padding, etc.)

## Files

- **index.css** or **main.scss**: Global styles
- **variables.css**: CSS variables
- **reset.css**: CSS reset
- **theme.css**: Theme configuration

## Best Practices

- Use CSS modules or styled-components for component styles
- Maintain design system consistency
- Use CSS variables for theming
